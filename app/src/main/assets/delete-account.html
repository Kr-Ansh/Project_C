Delete Account - Project C

Project C allows users to request deletion of their account and associated data.

If you would like to delete your account and all associated data, please send a request email to:

kranshdev20@gmail.com

Please include:

  • The email address used to create the account
  • Subject line: "Account Deletion Request – Project C"

What will be deleted:

  • Email address
  • Date of birth
  • Account data stored in Firebase
  • All associated in-game progress

Deletion Timeline:

Account data will be permanently deleted within 30 days of receiving the request.

If you have any questions, please contact us at the email above.
